# Estrutura de Dados e Algoritmos com Java

Este repositório contém meus códigos, anotações e exercícios desenvolvidos durante o curso de **Estrutura de Dados e Algoritmos com Java**, criado e ministrado pela instrutora **Loiane Groner**.

O objetivo deste projeto é consolidar o aprendizado prático sobre como organizar, armazenar e manipular dados de forma eficiente utilizando Java.
